# CBT - Sistem Ujian Berbasis Komputer

Sistem ujian berbasis web yang ringan dan mudah digunakan.

## 📋 Deskripsi
Proyek ini adalah aplikasi ujian berbasis komputer (Computer Based Test) yang dibangun menggunakan HTML, CSS, dan JavaScript murni tanpa kerangka kerja tambahan.

## ✨ Fitur
- [ ] Halaman masuk pengguna
- [ ] Tampilan soal ujian
- [ ] Penghitung waktu
- [ ] Penilaian otomatis
- [ ] Hasil ujian

## 🛠️ Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
